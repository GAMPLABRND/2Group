- **서론 / Introduction**

- **개요 / Overview**

본 문서는 한국제약바이오협회 (이하 ‘협회’) 의 2026년도 AI 바이브코딩 CSV 실습 교육과정의 2조가 GMP 교육 목적으로 자체 개발하는 전자로그북 관리 시스템 (ELMS, Electronic Logbook Management System) 에 대한 사용자 요구사항 규격서 (User Requirements Specification, 이하 ‘URS’) 이다.

본 시스템은 웹 애플리케이션과 데이터 저장용 구글 시트로 구성되며, GMP 환경에서 사용되는 장비들에 대한 다음의 업무를 지원한다.

- 장비 목록화 (시험장비, 분석장비, 시설, 설비 등의 Inventory)
- 장비 사용 현황에 대한 조회
- 장비 사용에 대한 전자 로그북 작성
- 장비 사용 기록서 (전자 로그북) 인쇄
본 URS는 ISPE GAMP 5 2nd Edition의 위험 기반 접근법 (Risk-based Approach) 및 End-User Developed Application (GPG E4) 지침에 따라 작성되며, 시스템의 설계, 구축 및 밸리데이션 수행을 위한 기준 문서로 활용된다.

-

- **목적 / Purpose**

본 문서의 목적은 다음과 같다.

- 전자로그북의 사용 목적 및 적용 범위를 명확히 정의한다.
- GMP 환경에서 운영되는 전자로그북의 기능적 및 비기능적 사용자 요구사항을 정의한다.
- 자체 개발 소프트웨어의 설계 및 구현을 위한 기초 입력 자료를 제공한다.
- 컴퓨터 시스템 밸리데이션 (CSV) 수행 시 위험 기반 접근법 (Risk-based Approach) 에 따른 테스트 기준을 정의하는 데 활용한다.
- 설계 적격성평가 (DQ) 및 후속 검증 활동의 기준이 되는 사용자 요구사항을 제공한다.

- **범위 / Scope**

- **주목표 및 장점 / Key Objectives and Benefit**

전자로그북은 다음을 목표로 한다.

- CSV 실습과정의 실습 대상 시스템 역할
- 수기 기록 업무의 전자화를 통한 기록의 정확성, 일관성 및 추적성 확보
- 역할 기반 접근 통제와 감사추적 (Audit Trail) 을 통한 데이터 완전성 (Data Integrity) 확보

- **사용 목적 / Intended Use**

교육과정을 통해 바이브코딩으로 구현되는 전자로그북의 사용목적은 다음과 같다.

본 시스템은 GMP 설비와 분석기기의 사용 이력을 전자기록으로 남기는 시스템이다. 사용자는 장비를 골라 사용 시작을 등록하고, 사용을 마치면 사용 후 상태와 특이사항을 남긴다. 시스템은 교정 유효기간이 지난 장비의 사용을 막고, 같은 장비를 동시에 사용하지 못하게 하며, 중요한 값을 수기로 넣을 때 정확한지 한 번 더 확인한다. 사용 후 상태가 이상으로 기록된 장비는 자동으로 사용중지되며, 조치 내용을 기록한 뒤 검토자의 승인을 받아야 다시 사용할 수 있다. 등록된 기록은 검토자의 전자서명으로 검토가 끝나고, 검토완료된 기록은 수정할 수 없으며, 기간별 로그북으로 인쇄된다. 잘못 등록된 기록은 삭제하지 않고 사유와 함께 무효 처리한다.

최종적으로 본 시스템은 제약바이오협회 CSV 실습과정의 검증 대상으로 사용된다.

-

- **시스템 적용 범위 / System Boundary**

본 URS에서 정의하는 전자로그북의 적용 범위는 다음과 같다.

- 웹 애플리케이션
- 데이터 저장용 구글 시트
- 사용자 PC의 웹 브라우저
- 데이터 완전성 기능

- Vercel, GitHub, Google 등 클라우드 플랫폼 서비스 요구사항
- Google Sheets와 같은 외부 관리형 서비스의 공급자 요구사항
- 기반 인프라, 보안 인증 체계, 가용성 및 재해복구 통제
- 교육장 네트워크 인프라

- **URS 처리 절차 / Procedure for Handling URS**

- **본 URS의 작성 배경 / Background**

- 전자로그북은 ISPE GAMP 5 2nd Edition의 시스템 분류 기준상 자체 개발 애플리케이션 (Cat.5 / End-User Developed Application, GPG E4) 에 해당한다.
- 외부 공급자가 별도로 존재하지 않으며, 실습 2조 내부적으로 협의하여 (사용부서, 품질보증부서, 소프트웨어개발팀, CSV SME) 역할을 분담한다.
- 이에 따라 본 URS의 검토는 실습조원 전체가 함께 협의하여 수행하며, 협의가 완료되면 최종 확정한다.

- **검토 및 승인 절차 / Review and Approval Procedure**

- 실습조원 전체는 본 URS의 작성을 주관하며, 실습 2조 내부 인터뷰 및 회의를 통해 사용자 요구사항을 도출하고 종합한다.
- 실습 조장은 품질보증부서 역할로서 본 URS의 최종 발효를 승인한다.
- URS가 최종 확정되면, 본 URS는 후속 산출물 (기능 사양서, 설계 사양서, 위험 평가 보고서, IOQ 등) 의 기준 문서로 사용된다.

- **개정 절차 / Revision Procedure**

- 본 URS의 변경은 승인된 변경 관리 절차에 따라 처리되며, 변경 사항은 본 문서의 개정 이력(Document History)에 기록된다.
- 변경에 따른 재밸리데이션 필요성은 내부 협의를 통해 평가하며, 평가 결과는 별도의 변경 관리 기록으로 보존된다.

| 로그북 | 검토완료된 기록 기준으로 장비별 로그북을 조회하고 인쇄하기 위한 화면 (조회 기간 지정) |
| 알람 | 사용 후 상태가 이상으로 기록된 장비와 그 조치 내용, 사용 재개 이력을 한눈에 보기 위한 화면 (재개 승인된 과거 이력 포함) |
| 비밀번호 변경 | 각 계정 개인의 비밀번호 변경을 위한 화면 |
| 감사추적 | Audit Trail 이력을 조회하고 감사추적 보고서를 인쇄하기 위한 화면<br>관리자와 검토자가 조회 조건 (기간, 행위자) 으로 이력을 조회하고 감사추적 보고서를 인쇄할 수 있다.<br>사용자 (TESTER) 는 접근할 수 없다. |
| 관리자 설정 | 관리자만 사용하는 화면으로 사용자 계정 관리전체 계정 현황 조회신규 계정 등록, 역할 지정계정 활성 또는 비활성 변경, 잠금 해제, 비밀번호 초기화환경 설정 값 관리비밀번호 정책 (복잡성, 유효기간, 잠금 기준) 설정자동 로그아웃 시간 설정 |
